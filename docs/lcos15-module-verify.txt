## USB coverage in Linux 7.2.6
# ax88179_178a (drivers/net/usb/ax88179_178a.c), vendor-class interface only:
#   0b95:1790 class ff/ff/00 — ASIX AX88179
#   0b95:178a class ff/ff/00 — ASIX AX88178A
# asix (drivers/net/usb/asix_devices.c): AX88172, AX88772, AX88772A, AX88772B, AX88178
# cdc_ncm (drivers/net/usb/cdc_ncm.c): generic
#   USB_INTERFACE_INFO(USB_CLASS_COMM, USB_CDC_SUBCLASS_NCM, USB_CDC_PROTO_NONE)
# 7.2.6 has no AX88179A / AX88772D symbol or device-id comment.
# Those chips use 0b95:1790 (bcdDevice 0x0200 AX88179A/B, 0x0300 AX88772D/E)
# and a CDC-NCM configuration. usb core prefers that non-vendor config, so
# cdc_ncm is the driver that binds them on this tree. CDC_NCM stays m.
# None of the three drivers call request_firmware. No firmware blob added.
